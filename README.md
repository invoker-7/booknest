### 🌱 GreenNest — ร้านผักสดออนไลน์ที่ออกแบบให้ “ดีและฟรี”

GreenNest คือแพลตฟอร์มร้านขายผักสดออนไลน์ที่นำแนวคิดจาก BookNest มาปรับให้เข้ากับธุรกิจอาหารสด โดยออกแบบประสบการณ์ใช้งานให้ **สะอาด สบายตา ทันสมัย และเข้าถึงง่าย** พร้อมรองรับทั้ง **Mobile App, Web App และ Desktop App**

จุดเด่นไม่ได้อยู่แค่หน้าตาที่สวย แต่คือการออกแบบระบบโดยคำนึงถึง **ต้นทุนการใช้งานจริง**

### 💚 ทำไม GreenNest ถึงน่าสนใจ?

**เพราะสามารถเริ่มต้นใช้งานได้โดยแทบไม่ต้องเสียค่าใช้จ่าย**

ระบบเลือกใช้เทคโนโลยีและบริการที่มี **Free Tier หรือ Open Source** เป็นหลัก ทำให้สามารถสร้างร้านค้าออนไลน์ที่มีหน้าตาทันสมัยได้โดยไม่จำเป็นต้องลงทุนกับ Infrastructure ราคาแพงตั้งแต่เริ่มต้น

ตัวอย่างเช่น

* 🌐 **Web App** — Deploy บนบริการที่มี Free Tier
* 🗄️ **Database** — ใช้บริการ PostgreSQL ที่มี Free Tier
* 📱 **Mobile App** — ใช้ WebView Wrapper เปิด Web App เดียวกัน
* 💻 **Desktop App** — ใช้ Web Technology เดิมมาทำเป็น Desktop Application
* 🛒 **ระบบร้านค้า** — ใช้ Backend และฐานข้อมูลชุดเดียวกันทุก Platform
* 🖼️ **Product Images** — ใช้ Object Storage ที่มี Free Tier
* 🔐 **Authentication** — ใช้ระบบ Authentication ที่มี Free Tier

ดังนั้นแนวคิดของ GreenNest คือ

> **Build once. Run everywhere. Pay only when you scale.**

แทนที่จะสร้างระบบแยกสำหรับแต่ละ Platform เราใช้ **Backend และ Design System เดียวกัน** แล้วปรับ UX ให้เหมาะกับแต่ละอุปกรณ์

### 📱 Mobile App

ออกแบบสำหรับการซื้อของอย่างรวดเร็ว

* Bottom Navigation
* Product Card ขนาดใหญ่ กดง่าย
* Search ที่เข้าถึงได้ทันที
* เพิ่มสินค้าเข้าตะกร้าได้จากหน้าแรก
* Checkout แบบสั้น
* ติดตาม Order จากมือถือ

### 🌐 Web App

เน้นการค้นหาและเลือกซื้อสินค้า

* Sidebar Navigation
* Product Grid
* พื้นที่แสดงสินค้าเยอะขึ้น
* Search และ Category Filter
* เหมาะกับการเลือกซื้อสินค้าหลายรายการ
* Responsive รองรับ Tablet และ Browser

### 💻 Desktop App

เน้นพื้นที่ทำงานที่กว้างขึ้น

* Sidebar แบบถาวร
* Multi-column Layout
* จัดการคำสั่งซื้อได้สะดวก
* ดูสินค้าและ Order พร้อมกันได้
* เหมาะกับการใช้งานบน Windows / macOS

### 🎨 Design Philosophy

ทั้งสาม Platform ใช้ Design Language เดียวกัน:

**Minimal · Pastel · Natural · Friendly**

ใช้สี Cream, Soft Green และ Orange เป็นหลัก พร้อมภาพผักจริงเพื่อสร้างความรู้สึกว่าเป็นร้านผักที่สดและเข้าถึงง่าย

เป้าหมายคือทำให้ผู้ใช้รู้สึกว่า

> **“การซื้อผักออนไลน์ไม่จำเป็นต้องยุ่งยาก”**

และในขณะเดียวกัน ผู้พัฒนาก็สามารถสร้างและทดลองระบบได้โดยมีต้นทุนเริ่มต้นต่ำมาก

### 🚀 จุดสำคัญที่สุด

GreenNest ไม่ได้พยายามแข่งด้วยการสร้างระบบที่ใหญ่ที่สุด

แต่เน้นแนวคิด

> **Small, simple, useful — and almost free to run.**

เริ่มต้นด้วยระบบที่จำเป็นก่อน ใช้ Free Tier และ Open Source ให้เกิดประโยชน์สูงสุด แล้วค่อยเพิ่มค่าใช้จ่ายเมื่อจำนวนผู้ใช้หรือธุรกิจเติบโตขึ้น

นี่ทำให้ GreenNest เหมาะทั้งสำหรับ **Prototype, Student Project, Startup MVP และธุรกิจขนาดเล็กที่ต้องการเริ่มขายออนไลน์โดยไม่ต้องลงทุน Infrastructure จำนวนมากตั้งแต่วันแรก**
